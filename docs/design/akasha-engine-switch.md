消息主体判定采用上游的 Ledger 只读解释，学习文本只包含用户 Input 与模型 Output；

这条窄接口不修改 ReAct 的历史恢复协议，也不让召回插件解释摘要或裁切原消息。

## 持久化与恢复

| 对象 | 允许变化 | 减少与恢复 |
|---|---|---|
| Message、Session、附件 | 原 owner 正常接纳新消息 | 本任务不删除或改写；用一致快照逐列及文件摘要核对 |
| 固定消息向量 | 原模型空间内补缺 | 不覆盖已有值；空间或内容冲突直接失败 |
| Akasha 图与进度 | 正式学习或重建增加/更新 | 重建前保留恢复点，候选通过校验后发布；在线进度与图同事务 |
| Default Memory 与回执 | 切换前按原协议结算 | 不自动减少；保留纠正、替换、撤回和显式记忆证据 |
| MEMORY、SELF、topics | 原 Markdown owner 按现行合同维护 | 不因切换删改；保留写前恢复点 |
| 主动记忆快照与授权 | owner 固定来源、范围、材料和回执 | 失效必须可见，不改投其他范围；保留已有操作历史 |

运行备份和验证副本留在 WSL 私有 operations 目录；不提交对话、向量、凭据或数据库。
上线期间的新消息必须正常保存，不能用旧 `sessions.db` 覆盖回退。
